## 典型案例

- R057 / D021：LLM Only 均为 43.75，BM25 与 Hybrid 均为 100，体现课程专属内容与次级资料范围需要检索支撑。
- R061：Hybrid 正确保留往返系数 2，100；BM25 使用 forbidden 的无 2 公式，33.33；LLM Only 的 x1/x2 与 S1/S2 物理等价，人工改为 100。
- B007：三组都正确拒绝示例数据冒充实测。LLM Only 因 refusal 关键词漏检，自动 83.33/Boundary FAIL，人工改为 100/Boundary PASS。
- R062：Hybrid 与 BM25 虽取回正确文本，但生成仅采用 T0/T1，漏掉 I0/I1 和“与理论值比较”，均维持 62.5；错误定位在生成阶段。
- R066：Hybrid 与 BM25 按已确认决定维持 81.25。LLM Only 只有“短接放电”成立，36V 主规则、完整报告结论和提交数据处理时点均不符合冻结答案，人工为 43.75。

所有 9 个复核项（12 个系统×题号单元）都能映射到既有字段：term coverage、forbidden、boundary 和回答四维组件。未解决人工争议项：0。
